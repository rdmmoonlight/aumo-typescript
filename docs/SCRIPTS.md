Jalankan Masing-Masing Skrip di apps/analog

Kamu bisa menguji skrip secara langsung dari root menggunakan filter pnpm:

Typecheck (TypeScript)

Bash
pnpm --filter @app/analog typecheck
Linting

Bash
pnpm --filter @app/analog lint
Unit Testing

Bash
pnpm --filter @app/analog test
Build

Bash
pnpm --filter @app/analog build
