# 1. Record Architecture Decisions

* Status: Accepted
* Date: 2026-10-19

## Context
Kami membutuhkan cara terstruktur untuk mencatat keputusan arsitektur proyek agar seluruh tim memahami konteks dan alasannya.

## Decision
Kami menggunakan format Architecture Decision Records (ADR) sederhana yang disimpan di dalam direktori `docs/adr/`.

## Consequences
Setiap perubah rancangan teknis skala besar wajib menambahkan file ADR baru sebelum implementasi.
